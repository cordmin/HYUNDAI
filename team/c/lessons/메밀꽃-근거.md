# 메밀꽃 필 무렵 근거

갈래 C 초안. 교사 검수 전. 확인 날짜는 모두 2026-11-02.

## 교사가 판단할 것

1. **물방앗간 이야기(b5, b6).** 원문은 하룻밤을 함께 보낸 일을 암시한다. 대본은 "이야기를 나누며 마음이 닿았지요", "평생 단 한 번의 인연", b6의 "살아온 보람이 된 하룻밤"(화면 문장)으로 낮추었다. 화면 문장의 하룻밤이라는 말을 남길지 정해야 한다.
2. **b3의 손찌검과 술자리.** 충주집 장면은 뺨을 때린 일과 낮술까지만 말했다. 충주집과 동이의 관계는 뺐다. b3은 필수가 아니다.
3. **동이가 아들이라고 단정하지 않았다.** 소설도 말하지 않는다. q2와 c1도 그 틀 안에서 썼다. 다만 q2는 "아들이라고 끝내 말하지 않습니다"라고 하여 아들일 가능성을 드러낸다.
4. **c1의 답은 해석이다.** "그리운 사람에게 닿으려는 길"은 소설의 직접 진술이 아니다. 백과사전이 전하는, 잊지 못해 봉평장을 찾는다는 읽기에 기댔다.
5. **b6의 외모 언급.** "얼굴이 얽어서"는 원문의 인물 설정이다. 듣는 사람의 외모를 묻는 것은 아니지만 뺄지 판단이 필요하다.

## 확인 안 함

- **판본:** 위키문헌 본문을 초판(『조광』 1936년 10월호)이나 종이책과 대조하지 않았다.
- **거리:** 소설 앞쪽에는 「육칠십 리 밤길」, 뒤쪽에는 「대화까지는 팔십 리의 밤길」이 나온다. 대본은 대화까지라고 밝힌 뒤의 것을 썼다. 앞쪽 숫자는 진부와 대화 어느 쪽이든 가는 장꾼들 이야기다.
- **낱말 뜻:** 장돌뱅이, 드팀전의 풀이는 국어사전 페이지를 열어 확인하지 않았다. 드팀전이 옷감 가게라는 것은 원문의 「무명 필과 주단 바리」로 판단했다.
- **b12 "시처럼 읽힙니다":** 백과사전의 평가를 내 말로 옮긴 것이다.
- **효석문화제와 봉평이 작가의 고향이라는 점:** 검색 요약에는 나왔으나 직접 연 「이효석」 항목에서 확인되지 않아 대본에서 뺐다.

## 일부러 넣지 않은 것

- 충주집과 동이 사이의 일, 허 생원의 충주집 짝사랑.
- 나귀가 날뛴 까닭과 아이들이 놀리는 대목.
- 투전, 의붓아버지의 폭력, 동이 어머니가 당한 일.
- 「달도 차지 않은 아이」라는 표현. 대사에는 "아이를 낳고 집에서 쫓겨났다"까지만 썼다.
