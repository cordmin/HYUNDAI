# J2 동백꽃 짧은 판 대본

2026-11-03 사용자 지시 「J2 우리가 대신 해주자」에 따라 작성한 대체 제작본이다. 다른 컴퓨터에 있는 J2 커밋 `686e750`의 내용은 확인하지 못했다. 그 파일을 복구하거나 검수한 결과로 표시하지 않는다. 업무표의 담당자는 바꾸지 않는다.

## 결과물

- `team/a/lessons/동백꽃-짧은판.csv`: m1~m11, 모두 판 8. 필수 8개, 선택 3개(m7·m9·m10). 기존 앱용 36조각은 수정하지 않았다.
- 필수 흐름: m1 질문·도입 → m2 마름과 소작 집안의 형편 → m3 감자 장면 → m4 닭싸움 → m5 이해 발문 → m6 결말 → m8 서술자와 독자의 인식 차이 → m11 정리·숙제.
- 선택: m7 꽃의 색과 감각, m9 관점을 바꾸는 분석 발문, m10 감정 이해와 행동 판단의 구별.
- 기존 `lessons/동백꽃.csv`의 장면·해석을 압축했다. m2는 b1·b2, m3는 b3·b4, m4는 b5·n4, m6는 b9·b10, m7은 b11·n8, m8은 b7·n6, m10은 n9, m11은 c1·c2를 바탕으로 한다.
- 점순이의 속마음은 해석으로 제시한다. 괴롭힘을 호감의 증거로 일반화하거나 정당화하지 않는다. 소년의 경제적 두려움, 작가와 서술자의 차이를 남겼다.
- 발문은 이해와 분석 두 개다. 운전자는 듣기만 해도 된다는 안내와 주차 후 숙제 표시를 유지했다. 대사에는 아라비아 숫자를 넣지 않았다.

## 검사와 인계

실제 앱의 CSV 파서·조각 변환 함수와 수업 조립기를 읽기 전용으로 사용한다. `node team/a/voice/check_short_lesson.js`가 규격, 필수 조각, 선택 조각의 여덟 조합과 실측 시간에 따른 오~구 분 조립을 확인한다. 결과는 `team/a/voice/동백꽃-짧은판-조립검사.json`이다. 초안 규격 검사·기술 검사이며 사람 교사 검수와 음원 청취 승인이 아니다.

음원과 기술검사표는 `team/a/voice/delivery/dongbaek-short/`에 납품한다. 이후 앱 담당은 기존 동백꽃 대본에 m1~m11을 추가하고 M4A를 넣은 뒤 길이 측정·빌드를 진행한다. J1의 기존 36조각 수정안은 이번에 받거나 적용하지 않았다. 이 대체본과 다른 컴퓨터의 J2안은 나중에 대조해야 하며 서로 다른 대본·음원을 섞으면 안 된다. 대본을 바꾸면 해당 음원도 다시 만든다.
