# T4 · 신청서 개인정보 부분 수정안

2026-11-03. 현재 코드(기준 `ee48557`)와 대조한 복사용 검토본이다. 작성된 신청서 원본은 저장소에서 찾지 못했으므로 실제 양식에는 아직 옮기지 않았다. 운영자 정보·보유기간·동의 절차까지 갖춘 법률 검토 완료 개인정보 처리방침으로 표시하지 않는다.

## 신청서에 옮길 문단

다잇은 학교·학년·반과 표시할 시간표·급식·학사일정을 차량 기기에 저장합니다. 아이의 이름·얼굴·성적을 필수로 입력받지 않습니다. 음성 답변은 Vosk로 기기 안에서 인식하며, 현재 앱 코드는 녹음 파일을 만들거나 음성을 서버로 보내지 않습니다. 수업의 「내 답 글로 남기기」는 기본 꺼짐이며, 켠 경우에만 발문 답을 글로 저장합니다. 답 글은 수업 기록 화면에서 지울 수 있습니다. 수업 완료 기록·숙제·학습 보상·월별 학습 이동 거리·이어 듣기 지점도 기기에 보관합니다.

「다니는 길 기억」은 보호자가 켠 경우에만 위치를 받아 집·학교·그 밖의 장소를 구별합니다. 경로 전체나 연속 좌표는 이동 기록으로 저장하지 않지만, 길 안내에 사용할 학교·집의 이름·주소·좌표·장소 식별자는 기기에 저장될 수 있습니다. 보호자가 직접 지정한 학교·집 좌표도 저장됩니다. 이동 기록에는 날짜·요일·시간대·장소 구분·문 열림 등이 포함됩니다. 기능을 끄면 이동 기록과 직접 지정한 좌표를 지우며, 내비에서 저장한 학교·집 장소 정보는 별도로 관리합니다.

학교·관광 자료를 받는 요청은 중계 서버와 해당 공공데이터 제공기관으로 전달됩니다. 이 경로는 음성·발문 답·이동 경로를 업로드하는 용도가 아닙니다. 요청 과정의 IP 등 접속 정보는 서버·호스팅 사업자에서 처리될 수 있어, 인터넷 통신이나 서버 측 정보 처리가 전혀 없다고 설명하지 않습니다. 출시 전 보호자 안내·선택 동의·삭제 절차와 사업자 로그 보유 정책을 최종 확인합니다.

## 구현과 맞춰 바꾼 점

| 피해야 할 표현 | 확인한 구현과 반영 |
|---|---|
| 개인정보는 수집·저장하지 않음 | 학교·학년·반, 선택 답 글, 학습·장소·이동 정보를 기기에 저장하므로 항목을 구체화 |
| 위치·좌표는 저장하지 않음 | 연속 경로는 저장하지 않지만 `dait.routePlaces`와 `dait.tripSpots`에 장소 좌표 저장 가능 |
| 기능을 끄면 좌표 전부 삭제 | 이동 기억을 끄면 `tripSpots`는 비우지만 내비 장소용 `routePlaces`는 유지. 전부 삭제라고 쓰지 않음 |
| 이동 기록은 정확히 60일 후 자동 삭제 | 현재는 여정 마감 때 기준일보다 오래된 기록을 정리. 앱을 오래 안 쓰면 정확한 시점의 삭제 보장 없음 |
| 모든 대화는 저장하지 않음 | 기본 등하교 대화와 선택 수업 발문 답을 구별. 선택 답 글은 저장 가능 |
| 서버를 전혀 사용하지 않음 | 학교·관광 공공자료는 Vercel 중계 사용. 사업자 접근 로그 여부는 별도 확인 |
| 보호자 동의를 이미 완료 | 기능 설명과 시스템 권한은 있으나 실제 동의 양식·운영 절차의 완료 증거 없음 |

## 제출 전에 정할 것

1. 수업 기록은 최근 200개를 유지하고, 이어 듣기는 7일 차이까지 추천한다. 날짜가 지났다고 저장값 자체를 즉시 지우는 구조는 아니다. 답 글·학교·장소·월별 거리의 보유기간과 전체 삭제 동선을 정한다.
2. 완료된 이동 기록은 여정 마감 시 60일 기준으로 정리하지만, 진행 중 여정에는 정확한 시작·정차 시각도 임시 저장된다. 설명을 완료 기록에만 한정할지, 저장 방식을 줄일지 정한다.
3. 중계 서버의 쿼리에는 학교 검색어·학교 코드·학년·반 등이 포함될 수 있다. 호스팅 로그·보유기간·운영자 접근권한을 확인한다.
4. 보호자·아동을 위한 동의와 고지, 위치정보 관련 절차의 적용 여부는 출시 전 담당자가 확인한다. 본 문서는 법적 적합성을 판정하지 않는다.
