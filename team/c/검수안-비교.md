# 팀원 AI 검수안과 지금 대본 비교 (동백꽃·소수)

2026-11-03 새벽 · 갈래 C(AI)가 만든 비교표다. 팀원 쪽 AI가 `codex/dait-lesson-voice` 줄기(따로 올린 작업 묶음)에 납품한 검수안과 음원을 지금 앱 대본(`team-base`)과 맞춰 보았다.

## 한눈에

| | 동백꽃 | 소수 |
|---|---|---|
| 조각 수 | 36 | 20 (짧은 판 m1~m11은 검수안에 없음) |
| 검수안에서 바뀐 대사 | 26 | 15 |
| 바뀐 화면 문장 | 3 (q3, n9, c2) | 3 (b2, b11, b12) |
| 음원 | 36개 모두 있음 | 20개 있음, 짧은 판 11개 없음 |
| 음원 글 = 검수안 글 | 36개 모두 같음 | 20개 모두 같음 |
| 음원 파일 지문(해시) | 36개 모두 맞음 | 20개 모두 맞음 |
| 실제 음원으로 잰 길이 | 15분 고르면 14.7분, 30분 고르면 20.8분 | 원래 판 전부 10.8분, 짧은 판은 음원 없음 |

**음원은 검수안 글로 만들어졌다.** 그래서 지금 대본을 그대로 두면 바뀐 조각(동백꽃 26, 소수 15)의 음원은 쓸 수 없다. 검수안을 받으면 음원을 바로 쓸 수 있다.

검수안은 사람 교사가 아니라 AI가 검수한 것이다. 팀원 쪽 문서에도 그렇게 적혀 있다.

## 앱에 넣어 둔 곳

2026-11-03 사용자가 「팀원 AI가 고친 글」을 확정본으로 정해 `team-base`에 합쳤다. 소수 짧은 판 11조각도 같은 방식으로 넣었다.

- 동백꽃: 대사 26개와 화면 문장 3개를 검수안으로 바꿨다.
- 소수: 대사 15개와 화면 문장 2개를 검수안으로 바꿨다. b2 화면 문장은 숫자 1을 쓰는 지금 표기를 그대로 두었다.
- 실제 음원 길이를 `lessons/음원길이.csv`에 쟀다. 그 결과 시험 두 개가 예상 길이에 기대고 있어서 실제 길이에 맞게 고쳤다.

## 동백꽃 검수안을 읽고 든 판단 (AI 의견, 교사 판단 필요)

좋아진 점

- 팀원 AI가 근거를 찾지 못했다는 수치(소작료 절반, n1)를 빼고 작품 안의 사실(집터, 양식 꾸어 먹기)로 바꿨다.
- n4의 「나는 제대로 대꾸도 못 합니다」를 고쳤다. 검수안은 원문의 소년이 울타리를 치며 소리친다고 한다(이쪽에서는 원문 확인 안 함).
- n6에서 작가와 이야기 속 「나」를 구별했다.
- 대조하지 못한 다른 작품(소나기)과의 비교(n9)를 뺐다.

걱정되는 점

- **「좋아해도 괴롭힘은 안 된다」가 자주 나온다.** 15분 수업에서 b7, q3, b14, q4, c1, c2 여섯 조각에 나온다(b7은 원래 있던 말). 문학 수업이 훈계처럼 들릴 수 있다.
- 해학과 웃음을 설명하던 n7, 이야기꾼 시점의 재미를 말하던 n6의 맛이 줄었다.
- **발문에서 「함께 탄 분이 있다면 이야기를 나누어 보세요」가 모두 빠지고 「속으로」로 바뀌었다.** 운전자에게 말을 시키지 않는 것은 맞다. 다만 다잇은 동승자의 답을 듣고 기록하는 기능이 있다. 동승자에게 건네는 말을 남길지 팀이 정해야 한다. 소수도 같다.
- s1과 c2에서 「다음 이동에서 이어 가요」가 빠졌다. 이어 듣기 기능과 맞물리는 말이었다.
- c2 숙제가 「점순이 마음을 한 문장으로」에서 「닭싸움의 까닭 한 문장」으로 바뀌었다. `lessons/목록.csv`의 숙제 칸은 아직 예전 말이다. 받으면 함께 고친다.
- b6의 「닭은 다음 날 아침에야 겨우 정신을 차립니다」는 원문 확인 안 함.
