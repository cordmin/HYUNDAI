# 화면 기준: Pleos 네이버앱

2026-11-01 팀 대화에서 이경민이 Pleos 네이버앱 사진을 공유했고, 「이 정도의 레이아웃과 텍스트」를 목표로 하기로 했다. 고태열도 UI 크기가 알맞다고 했다. 대사는 기능이 정해진 뒤 맨 마지막에 넣기로 했으므로 이번 작업에서 고치지 않았다.

새 화면을 본 뒤 일단 이 디자인으로 진행하기로 했다. 팀 최종 확정은 아니다.

## 사진에서 가져온 것

| 네이버앱 | 다잇 |
|---|---|
| 짙은 남색~보라색 바탕 | 같은 바탕을 모든 화면에 사용 |
| 「김그린님 / 햇살이 따뜻해요」 인사 두 줄 | 지금 여정의 한 문장과 짧은 설명 두 줄 |
| 오른쪽 위 둥근 검색 버튼 | 둥근 버튼 둘: 가 볼 만한 곳, 학교 설정 |
| 색이 있는 「투데이 브리핑 시작하기」 카드 | 「등교 대화 시작하기」 카드. 등교·하교·쉬는 날에 따라 색이 바뀜 |
| 예약 카드: 장소 한 줄, 시간 한 줄, 「안내 시작」 버튼 | 어디로 카드: 학교나 집, 남은 시간, 「학교로 안내」 또는 「출발하면 듣기」 버튼 |
| 작은 정보 카드 | 준비물, 시간표, 점심, 오늘의 질문 |

## 이경민 시안 반영 (2026-11-01)

이경민이 포토샵으로 그린 시안의 큰 글자 방향을 반영했다.

- 준비물과 점심은 카드 가운데에 크게 놓는다. 글자 수가 많으면 네 단계로 작아진다 (앱 창 기준 34, 26, 20, 17px).
- 시간표는 과목 이름을 두 글자로 줄여 크게 놓는다. 시안의 「국수체과도미」처럼 한 글자로 줄이면 국수, 도미 같은 다른 낱말로 읽히고 기술·가정, 자율·자치활동을 알아보기 어렵다.
- 위쪽 문장과 설명은 한 줄에 놓고, 길면 두 줄로 내린다.
- 어디로 카드의 시간 줄은 길 안내 중 남은 시간이 있을 때만 보인다.
- 오늘의 질문은 가운데 정렬한다.

## 첫 화면에서 뺀 것

여정 곡선 그림, 큰 시작 버튼, 카드 안의 설명 문장. 기능은 빼지 않았다. 대화 시작, 출발하면 듣기, 학교로 안내, 다른 여정 대화, 가 볼 만한 곳, 학교 설정, 예시로 듣기가 모두 남아 있다.

쉬는 날에는 어디로 카드 자리에 가 볼 만한 곳을 보여 준다.

## 그대로 둔 것

주행 화면은 문장 하나와 큰 버튼 둘을 유지한다. 색만 맞췄고 글자는 앱 창 기준 문장 30px, 버튼 22px로 크게 둔다.
