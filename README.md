# 다잇(DAIT)

현대자동차그룹 차량용 앱 개발 공모전(Pleos App Market) 출품을 준비하는 교육 앱입니다.

## 주요 기능

진주색 화면의 **지금·수업·기록** 메뉴로 이동합니다. 등교 대화와 준비물 안내는 제외했습니다.

- **시간 맞춤 수업** — 이동 시간에 맞춰 수업 분량을 조절합니다.
- **하교 대화** — 하루 이야기를 나눕니다.
- **재생 조작** — 멈춤·이어 듣기, 주차 중 구간 이동을 지원합니다.
- **깃털과 잇찌** — 수업을 마치면 깃털을 모으고, 로고가 까치 잇찌로 변합니다.

## 현재 상태

- 수업 5편: 동백꽃·소수·인공지능·하늘색·박과 리듬
- 앱 구현과 대본·음원 통합 완료. 재생·조작 등 기능 동작을 중심으로 확인 중입니다.
- 남은 일: 추가 기능 시험, 시연 영상, 최종 제출용 앱과 자료 제출

## 실행

**화면 미리보기:** Windows에서 `run_preview.bat`을 더블 클릭합니다.

**개발용 앱 빌드:** Java·Android SDK·Node.js를 준비한 뒤, 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Build-App.ps1
```

빌드 결과는 `apk/DAIT-dialogue-debug.apk`입니다. 환경 준비·에뮬레이터 설치·제출용 빌드는 [인수인계](인수인계.md)를 참고하세요.
