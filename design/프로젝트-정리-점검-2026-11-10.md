# 프로젝트 파일·테스트·코드 점검

2026-11-10 사용자 요청. 앱 배포 경로, HTML이 불러오는 스크립트, Kotlin 호출, 테스트 호출과 납품 문서 참조를 대조했다. 커밋되지 않은 기존 음원 원본과 `.claude/`, 다른 작업 폴더는 정리 대상에서 제외했다.

## 이번 정리

| 항목 | 확인과 조치 |
|---|---|
| 앱에 실려 있던 시험용 함수 2개 | `skipLessonPiece`, `seekLessonSection`은 실제 HTML·JS·Kotlin에 호출부가 없고 app.test.js에서만 사용했다. 함수는 시험 준비 코드로 옮겼다. 실제 재생 이동 함수와 검사는 유지한다. |
| 오래된 음원 개수 고정 검사 | tools/test_lesson_voice_export.py가 AI33·과학45개를 고정해 실제 대본이49·52개로 늘자 실패했다. 숫자 고정을 제거하고 대본 비어 있지 않음·고유 ID·수업 접두어·변경 감지·오래된 음원 내보내기 차단을 검사하도록 수정했다. |
| 오래된 시리즈 예상값 | 매미 음원이 생겨 실제 추천 후보가 된 뒤, app.test.js의 교시 예상 도우미가 시리즈 기본 켜짐을 반영하지 않아 실패했다. 실제 앱 규칙과 같이 시리즈 옵션을 넘기도록 고쳤고178개가 통과했다. 앱의 추천·재생 정책은 바꾸지 않았다. |
| 중복 내보내기 코드 | record-lesson-clips.py의 별도 ffmpeg 변환을 generate-lesson-voices.py의 공통 내보내기로 교체했다. 같은 AAC 변환에 원본/결과 해시·영수증·재시작 캐시 검증을 함께 사용한다. 현재 매미 ID도 제작 목록에서 처리한다. |
| 중복 주석 | dait-app-player.js의 동일 주석 한 줄을 지웠다. |
| 중복 Git 속성 | .gitattributes에 두 번 있던 같은 음악 CSV 규칙 한 줄을 지웠다. 적용 결과는 같다. |
| 오래된 안내 | README 수업 수·조각 수를 실제 목록에 맞추고, 삭제된 기획서·시연 각본 링크를 실제 남아 있는 개정안·초안으로 연결했다. 초안을 최종 각본으로 바꾸지는 않았다. 제작 도구의 청취 검수 대기 문구도 현재 지침에 맞춰 기술 검사 설명으로 정리했다. |

## 유지한 파일과 이유

- `android/app/src/test/js/*.test.js`: 재생·멈춤·이어 듣기·탐색·시간 맞춤·주행 제한·재생목록·배색·인트로를 확인하는 현행 시험이다. 단순 시험 파일이라는 이유로 지우지 않았다.
- `tools/test_lesson_voice_export.py`: 오래된 생성물을 앱에 내보내지 못하게 막는 유효한 오프라인 시험이다. 오래된 개수 조건만 바로잡았다.
- `team/a/voice/test_lesson_tts.py`, `test_short_lesson_tts.py`: 과거 납품 도구/문서와 연결된 담당자 자료다. 현재 앱의 공통 빌드 검사에는 포함되지 않는다. 이전 제작·검토 이력을 보존한다.
- `tools/dait-preview.html`: 중복 앱이 아니라 실제 앱 HTML로 보내는 5줄짜리 이전 경로 호환 파일이다.
- `team/a/voice/delivery/music-rhythm/rhythm-{8,15,20}min.wav`: 합계 약116MB로 크며 실제 앱은 조각별 M4A를 사용한다. 이전 납품물이라 이번에는 삭제하지 않았다.
- `voice/인공지능-청취본.mp3`: 약11MB 과거 청취 자료다. 앱 실행 자산이 아니며 기존 검토 이력을 보존한다.
- `downloads/`, `.gradle/`, `apk/`, Python 캐시: 설치·빌드 산출물/환경 캐시이며 Git에서 제외돼 있다. SDK·설치 파일·APK를 소스 정리와 섞어 삭제하지 않는다.
- `character/`, 보관 수업·검토 문서·디자인 화면: 앱에서 쓰지 않는 자료도 있지만 프로젝트 지침상 보관하는 이력이다. 앱에 다시 넣거나 다른 담당자의 자료를 삭제하지 않았다.

## 검사

TTS 통합 뒤 Node178개·음원 내보내기 Python2개·diff검사 통과. 개발 APK 빌드·Android 단위시험1개·lint 오류0(기존 경고7개) 통과. 전체309음원의 구조·디코딩과 새 매미 음원의 브라우저 재생·정지·이어 듣기·탐색·주행 제한·기록 저장도 확인했다. API 키는 코드·문서·Git에 기록하지 않는다.
