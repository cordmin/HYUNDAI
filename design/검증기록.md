## v0.2 — 주행 화면 간결화

2026-10-30 사용자 피드백 반영. `dait-drive.html`에서 확인.

- 주행 화면은 문장 하나, 조작 두 개. 시간표·급식·설명 문단·사이드 메뉴 제거.
- 일시정지 후 다시 듣기 버튼으로 전환, 넘기기 후 쉬는 상태 표시 확인.
- 플랫폼 제한 시 버튼 제거 및 재생 중단 상태 확인.
- 주차 중에만 오늘 준비의 세 항목 상세를 열 수 있음.
- 주차 중 안내 시작 → 등굣길 복귀 확인.
- 1024px 가로 화면 및 320px 좁은 화면에서 문장·조작 배치 확인.
- 실제 소리, 차량 상태, 주행 허용 여부를 검증한 것은 아님. 제한 상태는 외부 미리보기 도구로 선택함.

## v0.1 — 초기 시안

2026-10-30 · 로컬 브라우저에서 실제 클릭으로 확인.

- ‘짧게 함께 듣기’ 클릭 시 재생 상태·안내 대본 표시, 실제 소리는 재생하지 않음.
- 주행 제한 진입 시 재생 상태 종료, 상세 및 앱 메뉴 잠금.
- 도착 후 주차 → 가족 확인 → 완료 문구 표시.
- 하굣길 → 오늘은 쉬어 갈래요 → 재생 중단 및 건너뛰기 메시지.
- 가족 설정에서 질문 끄기 → 하굣길에 질문 없는 동행 화면 표시.
- 두 구성 전환 및 1024px 가로 / 360px 좁은 화면 배치 확인.
- 상태 저장 알림이 재생 상태를 초기화하던 문제 수정 후 재검증.

한계: 이 검증은 클릭형 화면 시안에 대한 것이다. Android 앱, 실제 차량 SDK, NEIS, 오디오 포커스, CarUxRestrictions, 한국어 음성 엔진은 아직 실행 검증하지 않았다.
