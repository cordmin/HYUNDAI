# L5 수업 중심 시연 음원 인계

2026-11-03. 현재 대화의 작업 범위는 음원 담당 사용자(L1~L5) 담당 업무만이다. 기획·앱 담당의 업무를 새로 진행하지 않는다. 한 줄 소개(N1)·보상 이름(N2)은 나중에 정하며, 이 파일의 문구를 팀의 확정 소개로 쓰지 않는다.

## 생성된 음원과 사용 위치

내레이션 12개·합계 51.76초를 생성했다. 전 조각이 각본의 장면 배정 시간 이내이며 기술 검사를 통과했다. `voice/시연-음원-수업중심.zip`에 내레이션 WAV·메타데이터·대본·편집목록·검사결과·이 인계서와 기존 앱 음원 6개, 총 34파일을 묶었다.

- 기준 대본: `voice/시연-내레이션.csv`. 수업 중심 촬영 작업본에서 내레이션 12개를 추출했다.
- 원본: `voice/generated/narration/nika/demo_01.wav`부터 `demo_12.wav`와 같은 이름의 메타데이터 JSON.
- `demo_12`는 미확정 소개 문구를 빼고 **「다잇.」만 읽는다.** 소개를 나중에 정하면 이 부분만 새로 만들면 된다. 나머지 문구는 현재 촬영 작업본의 내레이션을 따른다.
- 실제 길이·검사 상태·장면 연결: `voice/generated/narration/편집목록.csv`.
- 생성 명령: `python tools/generate-narration-voices.py`. 같은 대본·모델·스타일·목소리이면 완성된 테이크를 재사용한다. 기술 검사만 다시 하려면 `--check-only`를 붙인다.
- 목소리는 기존 Nika, 모델·키 조회·속도 제한·생성 잠금·테이크 보관은 기존 음성 작업실을 재사용한다. 앱 코드나 앱 음원은 이 작업에서 바꾸지 않는다.

## 기존 앱 음원

현재 수업 중심 촬영 작업본에는 등하교 규칙 대사가 없다. 보관된 규칙·조각 141개(B05)를 이번 작업에서 새로 만들지 않는다. 영상 장면에 필요한 아래 동백꽃 음원만 기존 앱 파일 그대로 묶음에 넣는다.

| 음원 | 쓰는 장면 |
|---|---|
| dongbaek_i1.m4a | 수업 시작 |
| dongbaek_q1.m4a | 이해 발문 |
| dongbaek_q6.m4a | 평가 발문 |
| dongbaek_q4.m4a | 창작 발문 |
| dongbaek_s1.m4a | 도착에 맞춘 짧은 정리 |
| dongbaek_r1.m4a | 다음 수업 앞의 지난 수업 복습 |

이 파일들은 실제 앱 대사를 보존하기 위한 자료다. 나중에 영상을 편집할 때 필요한 부분을 골라 쓴다. 아이의 답을 대신 녹음하거나 인식 결과를 꾸며 넣지 않는다.

## 검증과 남은 단계

생성본은 대본 지문·파일 해시·PCM16/mono·길이·비무음을 기계적으로 확인한다. WAV가 장면 배정 시간에 들어가는지도 수치로 검사한다. 이 검사는 발음·억양의 청취 판단이나 내용 검수 완료를 뜻하지 않는다. 실제 검사 수치는 `voice/generated/narration/편집목록.csv`와 `검사결과.json`을 본다.

내레이션 음원 생산과 영상 촬영·편집을 구분한다. 영상 촬영·편집(S8)은 앱 담당 담당으로 남기고 이 대화에서는 진행하지 않는다. 영상에서 내레이션과 앱 음성이 겹치지 않게 배치하고, 압축 시연·도착 시연 조작 자막은 촬영 작업본을 따른다.

공유 시트에는 L5 생산 결과와 사람 청취 후속, B06 납품, B05 이번 시연의 규칙 대사 추가 없음, 현재 작업 범위와 N1·N2 보류를 구분해 기록한다. 작업 브랜치는 `codex/taeyeol-tasks`, 이번 생성·도구 변경은 로컬 미커밋·미푸시다.
