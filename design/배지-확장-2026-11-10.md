# 기존 배지 스타일 확장

2026-11-10 사용자 승인 시안을 따라 과학·기술·음악·시리즈 완주 4종을 앱의 배지 둘러보기에 추가했다. 기존 6종과 보존 원본은 수정하지 않았다. 앱 배경은 바꾸지 않고 PNG 외부 배경만 투명하게 제공한다. 생성 이미지의 개별 분리·알파 정리를 기본 제공 ImageGen으로 수행했으며 픽셀 단위 원본 복사라고 주장하지 않는다.

10종을 5열 2줄로 표시한다. 500px 이하에서는 3열로 바뀌고 목록 안에서 스크롤할 수 있다. 기존 주행 중 기록 진입·탭 변경 차단을 유지한다. 보상 알림·효과음·획득 날짜는 추가하지 않았다.

초중고생과 성인의 기초 상식까지 아우르는 배움 분야·깊이·확장 규칙은 team/a/badges/extensions/체계-확장안.md에 제안으로 정리했다. 이번 작업은 디자인과 둘러보기 반영이며 개인별 배지 획득 시스템은 아직 없다.

## 확인 결과

- Node 앱 시험 178개 통과. git diff --check 통과.
- 기존 PNG 6종이 기준 커밋 8b4cda2와 바이트 단위로 같은지 확인했다.
- 추가 4종은 1254×1254 RGBA PNG이고 네 모서리는 완전 투명하다. 투명 비율 30~39%이며 수치는 manifest에 기록했다.
- 1200×780, 665×420(차량 기준), 390×844에서 이미지 10개가 로드되고 가로 넘침이 없다. 기존 6종 화면은 기준 커밋의 JS·CSS를 브라우저 요청에 제공해 같은 URL·상태·배경·크기로 비교했다.
- 주행 중 기록 진입과 배지 탭 조작 차단 유지. 콘솔의 오류는 기존 favicon.ico 404뿐이고 앱 JS 오류는 없었다.
- 화면: design/screens/badges-20261110/. 전 연령 공유안: team/a/badges/extensions/전연령-배지체계.png.

APK와 공개 배포본은 이번 작업에서 만들지 않는다. 배지 획득 조건과 세 깊이의 수업은 설계안이며 자동 지급을 구현한 것으로 기록하지 않는다.
