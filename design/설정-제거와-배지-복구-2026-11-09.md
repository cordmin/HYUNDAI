# 학교 설정·대답 기록 제거와 배지 복구

2026-11-09 사용자가 이미지의 학교·다니는 길 설정과 수업 대답 기록을 모두 제거하도록 요청했다. 이어 기록 메뉴의 기존 배지 보상용 그림은 유지하도록 지시했다.

- 설정 메뉴에서 학교·다니는 길 및 수업 대답 기록을 제거하고, 학교 검색·학년/반 선택·학교 삭제·설정 대화상자와 관련 스타일을 제거했다.
- 기존 학교·집·경로·학교 일정 저장값은 런타임에 불러오지 않는다. 다니는 길 기록과 위치 수집 요청은 껐으며, 이전 허용 응답이 도착해도 다시 켜지지 않는다. 기존 저장 데이터의 삭제는 하지 않는다.
- 수업 시작·출발 예약에서 대답 기록용 마이크 허락을 요청하지 않는다. 수업 음원 뒤 마이크를 열지 않고, 수업 대답을 저장하거나 이전 대답을 화면에 표시하지 않는다. 발문 뒤 생각할 시간은 유지한다.
- 기록 메뉴에 수업 기록/배지 탭과 기존 PNG 6장(첫 발견·국어·수학·탐험·골고루 탐험가·생활 속 발견가)을 복구했다. 획득 조건을 새로 만들지 않고 기존 둘러보기 상태를 유지한다. 깃털·도토리 수치와 캐릭터 보상 애니메이션을 다시 추가하지 않는다.
- 수업·숙제·이어 듣기 기록, 하교 대화, 재생 설정, 색상 설정, 주행 제한은 유지한다.

검사: 앱 JavaScript 211개 통과. 제거된 기능을 활성화하던 기존 UI 시나리오를 제거 상태·옛 설정 재활성화 방지·마이크 미요청·대답 미저장·배지 그림 6개 검사로 바꿨다. 수업 음원 224개 누락 0. Android 개발 APK·단위시험 5개·lint 통과. APK는 `apk/DAIT-dialogue-debug.apk`이며 최종 제출용 배포 파일이 아니다.

화면 직접 확인은 브라우저 도구의 로컬 file URL 접근 제한으로 수행하지 못했다. 파일 경로·화면 HTML·기능 동작은 자동 시험으로 확인했다.

작업 시작 시 이미 있던 별 헤는 밤 앱 통합, 보상 적립 제거, Dait 필기체 인트로 및 캐릭터 미커밋 변경을 보존했다. 다른 작업과 같은 파일에 변경이 겹쳐 있으므로 이번 작업에서 일괄 커밋·푸시는 하지 않았다. 담당·마감·다른 작업의 완료 상태는 바꾸지 않는다.
