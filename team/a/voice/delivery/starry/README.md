# 별 헤는 밤 TTS 납품

2026-11-08 사용자 요청으로 PR12의 대본 32조각을 제작했다. 기본판 22조각(복습·도착 정리 포함), 짧은 판 10조각이다.

- 앱 담당 전달용: 이 폴더의 `starry_*.m4a` 32개와 같은 이름의 변환 영수증 JSON 32개.
- WAV 원본·생성 정보: `voice/generated/lesson/nika/starry_*.wav`, `starry_*.json` 각 32개.
- 대본 원본: `team/b/lessons/starry/음원제작.csv`. 원문·구성·발문은 변경하지 않았다.
- 음성: 기존 수업 제작 설정의 Gemini 3.8 Flash TTS / Nika / 한국어 표준어. 출력 AAC M4A, 24kHz mono, 96kbps 설정.
- 실측 길이: `음원길이.csv`. 전체 32파일 합계 1010.840초(16분 50.840초), 개별 12.240~40.560초. 합계는 복습·선택·두 판 조각을 모두 더한 값으로 한 판의 재생 시간이 아니다.
- 기술 검사: `report.json`. 32개 대본 지문·원본/변환본 SHA256, PCM16 WAV 구조·비무음, AAC 형식·길이, 전체 파일 FFmpeg 디코딩 통과. 음원 누락 0개. 생성 후 재호출 없이 `--export-only`로 재현 확인했다.
- 발문 뒤 9·10초 기다림은 음원에 덧붙이지 않았다. 기존 앱이 처리한다.

## 재현

```powershell
python team/a/voice/starry_tts.py
python team/a/voice/starry_tts.py --export-only
```

기존 제작기의 키 조회·잠금·캐시·테이크 보관·M4A 내보내기를 사용한다. 같은 대본의 완성 음원은 재사용하며, 제작키는 저장소에 복사하거나 기록하지 않는다. 검사 중 ffprobe JSON의 한글 경로를 Windows 기본 인코딩으로 읽던 문제는 UTF-8 명시로 해결했다. 이 재검사에는 TTS API를 다시 호출하지 않았다.

## 앱 담당 인계

이번 완료 범위는 TTS 제작·파일 기술 검사·납품이다. 앱 목록·앱 assets·APK는 변경하지 않았다. 현행 앱은 기존 5편·192음원이며, 새 32개는 별도 납품 상태다. 대본 내용 검토나 음원 품질 청취를 수행하거나 승인한 것으로 기록하지 않는다.

앱 담당은 `team/b/lessons/starry/인계.md`에 따라 수업 CSV·목록을 적용하고 이 폴더의 M4A와 실측 길이를 반영한다. 실제 길이로 8분·15분 조립, 재생·멈춤·이어 듣기·시간 이동·도착 정리·주행 제한을 확인한 뒤 통합·빌드한다. 기존 `team/b/lessons/starry/기술확인.json`은 음원 제작 전 대본 납품 검사 이력으로 보존한다.
