## 결과와 기술 검사

- 현재 앱7편309조각, 파일 누락0. 35개 최신 대사·제작 fingerprint·원본 WAV SHA256·변환 M4A SHA256·영수증을 대조했다.
- WAV PCM16/24kHz/mono·길이·비무음 확인. 전체309개 AAC/24kHz/mono와 양수 길이, ffmpeg 전체 디코딩 통과.
- 실제 음원 길이표, 앱 대본·제작용 대본표, 저음~고음5칸 재생 막대 자료를 다시 만들었다.
- 개발 APK 빌드·Android 단위시험1개·lint 오류0(기존 경고7개)·Node178개·Python2개 통과. 기본 공용 빌드 출력의 파일 잠금은 다른 작업을 건드리지 않고 이번 작업용 출력 폴더로 피했다. 새 매미 음원은 Chromium에서 실제 재생·멈춤·이어 듣기·10초 탐색·주행 탐색 제한·기록 저장도 통과했다. 개발 APK는 `apk/DAIT-dialogue-debug.apk`, 최종 제출본과 구분한다.
- 8·15·20분 선택 조립은 모든 수업에서 제한 시간 안에 들어간다. 매미는 현재 대본 자체의 분량이 짧아8분 선택 약5:08,15/20분 선택 약8:50이다. 대본을 늘리지는 않았다.
- `voice/다시-만들-음원.csv`에 누적돼 있던95개도 현재 대사와 생성 기록·앱 파일이 맞는지 확인한 후 대기 목록에서 제거했다. 현재 대기0개, `record-lesson-clips.py --export-only`는0/0으로 정상 종료한다.
- API 한도에 걸린 요청은 멈추고 이미 만든 조각은 캐시로 이어갔다. 사용자가 제공한 키는 프로세스 안에서만 사용했으며 파일·Git에 저장하지 않았다. 이전 테이크는 로컬 takes에 보존한다.
