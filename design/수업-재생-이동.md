# 수업 재생 위치 이동

2026-11-06 사용자 요청: 수업을 처음부터 다시 듣고, 실제 음원 조각별 진행바에서 원하는 구간이나 구간 안의 시점으로 이동한다.

## 화면과 동작

- 주차 중 수업 화면 위에 「처음부터 듣기」를 표시한다. 현재 교시를 처음부터 시작하고, 이전 시도의 답과 중단 지점은 지운다. 앞 교시의 기록·보상과 이미 이동한 거리는 보존한다. 재시작 자체로 기록이나 보상을 추가하지 않는다.
- 화면 아래에 경과 시간·현재 구간 번호·전체 시간, 음원 조각 경계가 나뉜 진행바를 표시한다. 진행바를 움직이면 구간 안의 원하는 초로 이동한다.
- 진행바 아래 가로로 넘기는 구간 버튼은 실제 조각의 화면 문장으로 표시한다. 구간 버튼을 누르면 해당 조각의 처음으로 이동한다. 44px 이상 터치 영역과 키보드/스크린리더용 레이블을 유지한다.
- 멈춘 상태에서 이동하면 계속 멈춰 있고, 이어 듣기를 눌렀을 때 선택한 위치에서 재생한다. 브라우저는 새 파일 metadata가 준비된 뒤에도 위치를 적용한다. Android는 순번이 맞는 현재 MediaPlayer에 seek를 적용하고 실제 위치를 화면에 알린다.
- 건너뛴 조각이나 뒤쪽만 들은 조각을 전체 청취 분량으로 더하지 않는다. 이전에 끝까지 들은 조각을 다시 들어도 같은 시도의 분량은 중복 집계하지 않는다.
- 주행 중에는 처음부터 듣기·진행바·구간 버튼을 숨기고 이동 요청도 거절한다. 기존 주행 화면의 이전·일시정지/이어 듣기는 그대로 둔다.

## 검사

JS 테스트 195개 통과: 처음부터 듣기, 이전 교시 기록 보존, 재시작 보상 중복 방지, 구간/초 단위 이동, 일시정지 유지, 새 파일 metadata 적용, 질문 뒤 기다림으로 이동, 건너뛰기 보상 방지, 주행/주차 전환을 포함한다.

실제 브라우저에서 음악 수업의 구간 선택과 오디오 currentTime, 멈춘 상태에서 마지막 조각 내부로 이동(52.78초/52.84초), 처음부터 듣기, 주행 중 이동 UI 제거와 주차 후 복원을 확인했다. 화면 근거는 이번 채팅의 `lesson-progress.png`다. Android 네이티브 연결은 APK 빌드·단위 시험·lint로 검사하며 기기에서 탐색을 직접 조작한 검수와 구분한다. 내용의 사람 검수·음원 전수 청취 승인은 수행하지 않았다.
