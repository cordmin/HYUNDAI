# 등하교 첫 화면과 안내 흐름 v2

2026-10-30. 목적을 알 수 없는 재생 화면이라는 피드백을 반영한 네이티브 앱 변경.

- 첫 화면: 다잇 / 등교 준비·하교 대화, 좌측 동행 캐릭터·우측 짧은 소개, 등교 준비·하교 이야기 두 진입 카드.
- 등교: 체육복 준비 확인 → 기대되는 시간 질문 → 도착 시 가방 확인.
- 하교: 오늘의 기억 질문 → 가족과 이야기 → 집 도착 마무리.
- 안내: 문장 하나, 정적인 세 단계 표시, 안내 듣기·다음 안내. 마지막은 마치기로 첫 화면 복귀. 처음으로 버튼으로 언제든 조용히 종료.
- 학교 안내: 가상 학교·학급·시간표·학교 준비물 안내. 실제 데이터 미연동 표시.
- 시연 설정: 기존 48개 대사·두 목소리 유지. 학교 안내→시연 설정 또는 안내 화면 상단 설정에서 접근.
- 새 아이보리/초록/노랑과 Canvas 벡터 동행 캐릭터는 검토용 제안. 사용자가 승인한 것은 좌측 캐릭터·우측 메시지·하단 조작의 배치뿐.
- 기존 CarUxRestrictions 처리 유지. 제한 시 재생과 탐색을 막음. 음원과 MediaPlayer·TTS·오디오 포커스 코드는 변경하지 않음. 노이즈 해결을 주장하지 않음.

학교/내비/음성 인식/실시간 대화 연결은 이번 변경 범위에 포함되지 않는다. 사전 제작 음원의 수동 시연이다.
