# 별 헤는 밤 · 8분·15분 이동용 대본 납품

2026-11-08 · 이지민 추가 제작. 출발 자료는 서경원 담당 C06-4의 `team/c/lessons/별헤는밤.csv`다. 기존 원본·담당·납품 이력은 보존했다.

오늘의 질문: **별을 헤는데 왜 숫자가 없을까요?**

목표: 반복되는 표현과 앞뒤의 마음 변화를 소리로 이해하기. 시가 직접 말한 장면과 내가 짐작한 뜻을 구별하기. 학년별 성취기준 번호를 확인하거나 특정 교과서 차시에 연결한 자료는 아니다.

## 납품 파일

- `별헤는밤.csv`: 앱 빌더 형식의 원본 데이터 32조각. 기본 판 22개(복습·도착 정리 각 1 포함), 짧은 판 전용 10개.
- `대본-8분.md`, `대본-15분.md`: 읽기용 대본. 기본 판의 선택 조각에는 ‘시간이 남으면’을 표시했다. 선택 조각을 모두 넣어 정확히 15분인 고정 낭독본이 아니다.
- `발문과-응답.md`: 5개 발문, 응답 참고, 무응답 처리, 도착 후 한 문장 활동. 새 응답 분석 기능은 없다.
- `음원제작.csv`: 32개 음원 이름·대사·구분, 상태는 모두 대기. 기존 빌더 출력과 일치한다.
- `목록-추가행.csv`: 실제 목록에 추가할 후보 한 행과 헤더. 현재 앱의 목록은 변경하지 않았다.
- `근거와-이용범위.md`: 다섯 후보의 국내 원문 이용범위, 새 대본의 계보와 원문·해석 구분.
- `check.cjs`, `기술확인.json`: 실제 저장소 빌더와 수업 엔진을 임시 폴더에서 실행한 재현 절차·결과.

## 시간 확인

2026-11-08 main의 `tools/build-lessons.js`, `dait-lesson.js`로 분리 검사했다. 기존 수업·앱 생성 파일은 변경하지 않았다.

| 이동 시간 | 실제 조립 | 예상 재생 길이(대기 포함) | 비고 |
|---|---|---|---|
| 8분 | 짧은 판 10조각 | 약 7분 28초 | 복습 없음, 발문 2개 |
| 15분 | 기본 판 19조각 | 약 14분 37초 | 선택 조각 f_b13 제외, 발문 3개 |

예상 길이는 앱의 초당 4.62자 기준이며 실제 음원을 재거나 청취한 결과가 아니다. 기다림은 기본 판 각 9초, 짧은 판 각 10초다. 내비게이션의 도착 예정 시간이 달라지면 기존 엔진이 남은 선택 조각을 조절하고, 시간이 부족하면 `f_s1` 도착 정리로 이어 간다. 이 분기는 두 판 모두 확인했다. 짧은 판은 도착이 늦어져도 기본 판으로 갑자기 바꾸지 않는 기존 규칙을 따른다.

검사: `node team/b/lessons/starry/check.cjs` 통과, 기존 `node --test android/app/src/test/js/lesson.test.js` 51개 통과. 음원 생성·기기 재생·앱 빌드·배포는 이번 완료 범위에 없다. 대본 내용의 사람 검수·음원 품질 청취를 후속 필수 조건으로 추가하지 않았다.

## 음원·앱 담당에게 넘길 순서

1. 음원 담당은 이 폴더의 CSV를 받는다. 새 수업 ID는 `starry`, 조각 ID는 `f_*`와 `s_*`이며 32개 모두 새 음원이 필요하다. 기존 타 수업이나 C06-4 초안의 음원 이름을 덮어쓰지 않는다. 쉼 9·10초는 앱이 처리하므로 음원에 덧붙이지 않는다.
2. 앱 담당이 적용할 때 `별헤는밤.csv`를 `lessons/`로 복사하고, 실제 `lessons/목록.csv`에 후보 행만 추가한다(헤더 중복 금지). 그 뒤 기존 제작 도구의 `starry` 선택으로 음원을 만들고 `node tools/build-lessons.js`를 실행한다. 공유 제작키를 이 폴더에 복사하지 않는다.
3. 음원 파일 누락·길이·시작/멈춤/이어 듣기·초/분 이동·도착에 맞춘 정리·주행 제한을 기술 확인한 뒤 통합·빌드한다. 이 대본 PR 병합만으로 음원 32개나 앱 수업 1개가 완료된 것으로 집계하지 않는다.
4. 실제 수업 목록은 음원 0개·앱 미반영 상태로 기록한다. 현행 동백꽃 포함 5개 앱 수업과 기존 192개 음원 집계는 그대로다.

보상·캐릭터는 이번 대본에서 이름을 새로 정하지 않았다. 다람쥐·도토리 원본이 올라오기를 기다리는 작업과 독립적으로 넘길 수 있다. PR11의 UI·차량·모드별 색상 작업과도 별도 납품이다.
