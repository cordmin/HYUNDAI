# 차량 재생 상태·책임 분리 보완

2026-11-07~08. 객체 구조·차량 UX 검토 후 사용자 승인으로 반영했다.

- `dait-playback.js`: LessonSession이 재생 상태를 소유하고 기존 run.paused/stopped/done은 같은 상태의 접근자로 연결한다. AudioAdapter가 browser/native의 speak·playClip·stop·hold·resume·seek·rate·volume을 연결한다. ArrivalPlanner, VehiclePolicy, SettingsStore와 명시적 화면 이벤트로 책임을 분리한다.
- 색상/음량 파일의 전역 renderStage/renderPearlNav/setDrivingMode 덮어쓰기를 제거했다. 화면 렌더·차량 제한 변경·뒤로가기 이벤트를 구독한다.
- 네이티브 오디오 중단·복귀 시 버튼·파형·안내·차량 미디어 상태를 함께 갱신한다. 사용자 멈춤 뒤 시스템 재개는 거절한다. Native VoiceSession은 보류된 포커스 재요청과 paused 상태 배속 변경을 처리하며, 멈춘 MediaPlayer에 배속을 적용해 잠깐 재생되는 것을 피한다.
- 학교 설정은 모달로 열며 수업 모드·위치·일시정지를 유지한다. 검색 입력은 수업 렌더가 발생해도 보존한다. 학교 저장/삭제도 수업 종료를 호출하지 않는다. 시스템 뒤로가기에서는 팝업을 먼저 닫는다.
- MediaSession에 앞뒤 시간 이동, 실제 재생 위치·길이·배속을 연결했다. 주행 제한 시 시스템 미디어의 절대 탐색 액션도 제거하고 JS 명령에서도 차단한다. 실제 핸들 키/호스트의 액션 표시는 장치에서 확인해야 한다.
- 나레이션은 배속을 적용하고 생각할 시간·교시 휴식은 실제 초 단위로 유지한다. 남은 수업 시간과 ETA에 맞춘 계획도 같은 시간 비용을 쓴다.
- 하단은 `수업 mm:ss 남음`으로 구분하고 중단·일시정지·도착 마무리 상태를 표시한다. 주행 중 파형은 멈춘다. 보조 조작 영역을 확대하고 야간 배경에서는 설정·음량 패널도 어둡게 표시한다.
- isDebugBuild 브리지를 추가해 제출용 빌드에서 개발 시연 조작을 숨기는 기존 경로를 실제 연결했다. 원래 OS CarUxRestrictionsManager 판단은 유지한다.

검사: Node218개 통과. Chrome1000×632/665×420/420×640에서 중단/수동멈춤 우선, 학교 설정의 동일 세션·입력 유지, 실제 음원 경계 이동·멈춤·0음소거, 주행 파형 정지·설정 차단, 기본 설정 넘침 없음 확인. 브리지 대역으로 실제 위치·배속·탐색 허용 패킷을 확인했다. 야간 설정 화면의 색·가독성을 수동 확인했다.

미확인: Android SDK/JDK가 준비되지 않아 APK 빌드·실제 차량의 통화/내비 오디오 포커스·핸들 키·화면 밀도/야간 실물 가독성은 검증하지 못했다. 브라우저/브리지 대역 시험을 실기기 검증으로 표시하지 않는다. GitHub·시트 납품 상태는 로컬 인계 기록 참조.
