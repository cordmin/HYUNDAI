# 수업 화면·설정 대조 (2026-11-07)

기준: 기존 공유 시안 `work/dait-share-site/dist/app.js`의 playerMarkup/settingsMarkup/playbackFormMarkup와 실제 공동 앱.

| 항목 | 변경 전 실제 앱 | 이번 반영 |
|---|---|---|
| 전체화면 수업 재생 | 큰 카드·구간 목록·이전/일시정지, 주행 시 별도 화면 | 로고·ETA·우상단 도구, 문장·파형·원형 재생·앞뒤 시간 이동, 넓은 진행 바를 동일 화면으로 사용 |
| 뒤/앞 시간 이동 | 구간 기준 이전만 제공 | 기본 15초/30초. 각 방향 독립 설정, 15초·30초·1분·2분 및 직접 입력 |
| 초·분 직접 입력 | 없음 | 초 1~3600, 분 1~60. 설정 저장 후 적용 |
| 재생 속도 | 없음 | 0.8/1.0/1.2/1.5/2.0. 브라우저 음원·무음 대기·남은 시간, Android MediaPlayer 연결 |
| 재생 설정 저장 | 없음 | 기존 시안과 동일한 저장 키로 이 기기에 저장·복원 |
| 대화 중 질문 | 학교 설정 화면에만 존재 | 설정 팝업에 노출, 기존 기능 연결 |
| 수업 대답 기록 | 학교 설정 화면에만 존재 | 설정 팝업에 노출, 기존 동의·기기 저장 동작 유지 |
| 말로 답하기 | 음성 인식 가능 기기에서 학교 설정 화면에 존재 | 가능한 기기에 설정 팝업에도 노출 |
| 학교·학년·반, 다니는 길 | 기존 전체 설정 화면 유지 | 팝업에서 학교·다니는 길로 연결. 학교 검색·위치 권한/기억 기능 보존 |
| 앱 색상 | 2색 색상판·상세 코드 입력 존재 | 보존 |
| 세로 음량, 0 음소거 | 존재 | 보존 |
| 처음부터 듣기 | 재생 화면 상단 | 설정 팝업으로 이동, 기존 기능 유지 |
| 주행 제한 | 상세 탐색·설정 차단 | 설정 차단·운전 시작 시 팝업 닫기. 정해진 앞뒤 시간 이동은 허용, 진행 바 자유 탐색은 주차 중만 허용 |
| 도착 맞춤·정리·깃털 기록 | 공동 앱에 구현 | 기존 로직 유지, 배속에 맞춘 예산 환산·남은 시간 표시 연결 |

Android APK 빌드 및 실제 기기에서의 배속·주행 신호 검증은 이 환경에서 확인하지 못했다. GitHub/시트 반영 상태는 작업 인계 문서 참조.

검사: Node 209개 통과. Chrome1000×632/665×420/420×640에서 실제 음원 시간 이동·구간 경계·일시정지 유지·초분 설정·저장복원·실제 playbackRate·주행 잠금·ETA 표시 통과. 665×420 기본 재생 설정은 스크롤 없이 들어간다.

구현: 기존 수업 타임라인을 현재 음원 offset으로 환산한다. 정해진 시간 이동은 주행 중 제공하고 자유 탐색은 주차 중만 허용한다. metadata를 불러 일시정지 중 새 음원으로 이동해도 offset을 적용한다. Android setSpeechRate 브리지는 현재/다음 MediaPlayer와 paused 상태를 유지하며 대화 음성은 정상 속도로 재생한다.
