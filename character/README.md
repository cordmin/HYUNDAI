# 다잇 로고 새 캐릭터

2026-11-04 · 다잇 로고의 리본 한 획이 끊기지 않고 이어져 작은 새가 되는 캐릭터 시안을 모은다. **2026-11-04 결정: 캐릭터는 calm-v2로 확정.** 앱 코드에는 아직 넣지 않았다.


## 로고에서 새로: 어디가 무엇이 되나

| 로고 | 새 |
|---|---|
| D의 둥근 고리 | 둥근 머리와 뒤통수의 말림 |
| a·i의 물결 | 흰 가슴과 남색 날개 사이의 두 번 출렁이는 물결 |
| i 위의 빛나는 점 | 눈 |
| t의 세로획 | 꼬리 윗선 |
| t의 가로줄 | 꼬리 끝에서 리본을 '十'으로 가로지르는 짧은 선 |

색은 로고 그대로다: 리본 하늘색 #38BDF8 → 흰색, 머리·등 남색, 배 흰색, 바탕 #0B1220.

## 움직임

- [logo-to-bird.html](logo-to-bird.html): 브라우저로 열면 로고가 약 4.4초 동안 새로 바뀐다. '다시 보기'와 막대로 장면을 넘겨 볼 수 있다. 주소 끝에 `?t=1600`처럼 붙이면 그 순간에서 멈춘다.
- 순서: 로고의 i 점이 톡 튐 → 리본이 부리 쪽부터 꼬리 쪽으로 차례로 구부러짐 → i 점이 포물선을 그리며 눈 자리로 → t 가로줄이 꼬리 끝으로 → 머리, 날개, 배, 꼬리 순으로 색이 차오름 → 가지가 그어지고 내려앉음 → 한 번 깜빡임.
- 새 그림은 calm-v2 코드 원본의 선과 색을 그대로 쓴다. 로고 획과 새 리본을 9개 구간으로 짝지어 같은 구간끼리 점을 맞추는 방식이라, 선이 끊기지 않고 휘어진다.
- 앱 화면이 HTML·SVG로 그려지므로(`android/app/src/main/assets/dait-preview.html`) 같은 방식으로 넣을 수 있다. 아직 넣지 않았다.

## 정하지 않은 것

- 움직임 순서: 지금은 로고 → 새. 팀에서 새가 먼저 나오고 로고가 나중에 나오는 순서(영화 인트로처럼)와 날갯짓을 넣은 영상이 나왔다. 그 영상은 이 폴더에 없다.
- 이름. 보상 이름(N2)과 함께 나중에 정한다.
- 새가 말을 하는지. 지금은 말하지 않고 곁에서 반응만 하는 동행으로 검토 중이다(말풍선·입 모양 없음).
- 앱 어디에, 언제 보여 줄지.
- 사람 검수는 하지 않았다.
