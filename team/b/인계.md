J1~J3의 「결과물 납품 완료」는 사람 교사가 직접 읽고 승인했다는 뜻이 아니다. 사용자 위임에 따른 AI 검토이며, 앱 반영·최종 승인과 분리한다. 공유 검수본 고유 링크·최신 AI-업무분장.md가 제공되지 않아 현재 업무표의 업무 설명과 최신 저장소를 기준으로 진행했다. 다른 담당자의 업무·마감·결정을 바꾸지 않는다.

## 앱 담당이 합치는 순서

1. 기준 `team-base`의 `3f860bc` 이후 `lessons/동백꽃.csv`가 바뀌었다면 먼저 대조한다. 이 폴더는 기준본의 36조각을 검토했다.
2. 기존 긴 판도 손볼 경우 `lessons/동백꽃-수정안.csv`와 `변경목록.json`을 검토한다. 기존 36개 조각 ID는 유지했다. b4·b7만 필수로 추가했고 n1 화면 제목만 고친 변경은 녹음이 필요 없다.
3. 짧은 판만 먼저 받을 경우 `lessons/동백꽃-짧은판.csv`의 11개 행을 현행 CSV 뒤에 추가한다. 기존 m 조각이 없는지 확인한다.
4. 둘 다 받을 경우 `lessons/동백꽃-통합제안.csv`를 검토 후 사용한다. 총 47조각이며 이미 합친 표라 11개 행을 다시 붙이지 않는다.
5. 새 m 음원은 `dongbaek_m1.m4a`~`dongbaek_m11.m4a`. 수정된 기존 대사 13개는 `r1,b5,b7,q2,n7,q3,b13,b14,q6,q4,c1,c2,s1`이다. 기존 음원을 새 글에 그대로 연결하지 않는다.
6. 확정 대사로 수업 음원 목록을 갱신하고 음원을 제작한 뒤 실제 길이를 측정한다. 제출용 누락 검사·재생·사람 청취를 수행한다. 이번 작업은 새 음원과 APK를 만들지 않았다.
7. 도착 여유 20초 예산이 선택 조각 추가 때 줄어드는 현행 조립 동작은 `동백꽃-검수.md`의 재현값을 보고 수정한다. 이 문제는 대본 CSV 변경만으로 해결되지 않는다.

짧은 판의 숙제는 기존 목록.csv의 닭싸움 까닭 한 문장과 맞췄으므로 숙제 제목 변경은 필요 없다. 수업 목록의 교사 검수 상태도 사람 승인 전에는 완료로 바꾸지 않는다.

## 확인한 것

- 현행 build-lessons.js 파서·조각 생성 함수로 3개 CSV 규격 확인, ID 중복 없음.
- 현행 dait-lesson.js로 현재 15·30분 재현, 제안 대본 5~9분 짧은 판·10/15/30분 일반 판 조립 확인.
- 짧은 판의 선택 조각 유무 8조합에서 핵심 장면·두 발문·풀이·정리·숙제 유지 확인.
- 원문 전사본 대조. 생강나무·작가 생몰 정보는 별도 공개 출처를 열어 확인.
- 기존 여정·수업 JavaScript 시험 184개 통과. 앱 코드와 활성 lessons/·voice/ 파일은 변경하지 않았다.
- PDF 한 장 렌더링과 한글·줄바꿈·넘침을 확인했다.
- 자세한 수치와 변경 조각은 `조립-검사결과.json`, `변경목록.json`에 있다.

## 확인하지 않은 것

사람 교사의 직접 낭독·승인, 새 대본의 실제 음원·청취, 차량·에뮬레이터에서 새 대본 재생, 공유 검수본 댓글, 초판 영인본 교감, 새 짧은 판의 학습 효과는 수행하지 않았다. 기존 앱 시험 통과가 이 항목을 대신하지 않는다.
