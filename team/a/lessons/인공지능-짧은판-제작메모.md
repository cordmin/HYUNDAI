# T8 AI 짧은 판 대본

2026-11-03 사용자 지시 「T8도 우리가 가져오자」에 따라 기존 AI 수업을 압축해 작성했다. 업무표의 담당자는 유지한다. 결과물은 `team/a/lessons/인공지능-짧은판.csv`이며 앱 대본은 아직 바꾸지 않았다.

## 구조와 근거

- 판 8, m1~m11, 필수8·선택3(m7·m9·m10). 필수 흐름은 질문 → 지도학습의 입력·정답 → 접시 색 가정 → 이해 발문 → 새 조건의 평가 → 언어 모델 → 단정적인 오류·출처 확인 → 정리·선택 숙제다.
- 이해 발문 m4와 분석 발문 m9의 기다림은 각각9초다. 질문은 건너뛸 수 있고 운전 중 검색·입력·계산을 요구하지 않는다.
- 기존 `lessons/인공지능.csv`에서 m2는 b1·b3, m3~m5는 b4·q2·b5, m6는 b9, m7은 b7, m8·m9는 b10·b11, m10은 b6, m11은 c1·c2를 바탕으로 했다. 기존22조각과 그 음원은 수정하지 않았다.
- 과일·접시는 설명용 가정이다. 실제 모델의 관찰 결과로 말하지 않는다. 과일 분류와 언어 생성을 같은 과제로 설명하지 않고, 모델의 표현을 사람의 확신·고의와 구별한다.
- 예시 메시지는 정상 아흔아홉·스팸 하나로 백 개다. 모두 정상이라고 답하면 정답 아흔아홉·스팸 탐지 영이다. 실제 서비스 성능 수치가 아니다.
- 대사 속 숫자는 한글로 썼다. 모델이 매번 인터넷을 검색한다거나 데이터가 많으면 반드시 정확하다고 말하지 않는다. 개인정보 입력도 요구하지 않는다.

2026-11-03 다시 확인한 기본 개념은 [Google 지도학습](https://developers.google.com/machine-learning/intro-to-ml/supervised)의 입력·레이블·학습·새 자료 추론, [Google 언어 모델 소개](https://developers.google.com/machine-learning/crash-course/llm)의 문맥·토큰 예측·그럴듯한 생성 설명이다. m10의 개념은 [Google 과적합](https://developers.google.com/machine-learning/crash-course/overfitting/overfitting)과 [평가 자료 분할](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets)에서 학습 성적과 새 자료의 차이, 평가 자료 재사용의 한계를 대조했다. 추가 사실 근거와 주의점은 기존 `team/a/lessons/인공지능-근거.md`에 기록된 자료를 따른다. 원문을 번역해 옮긴 대본이 아니라 기존 프로젝트 대본을 압축한 제작본이다.

## 검사·납품·후속

`node team/a/voice/check_short_lesson.js ai`는 실제 앱 CSV 파서·조각 변환기·조립기를 읽기 전용으로 호출한다. 음원 제작 후 실측으로 오~구 분 조립, 필수8·선택3, 선택여덟 조합을 검사한다. 결과는 `team/a/voice/인공지능-짧은판-조립검사.json`이다.

음원 생성은 기존 Nika 도구를 재사용하며 대본 지문·원본 해시·PCM16/mono·비무음·AAC 변환 길이를 확인한다. 결과물은 `team/a/voice/delivery/ai-short/`에 있다. 동백꽃 짧은 판과 함께 L6 납품 대상이다.

사람 교사 검수·사람 청취·앱 통합은 별도 후속이다. 기존 L4 인공지능22개 청취 완료 기록을 신규11개 음원 승인으로 확대하지 않는다. 앱 담당은 이 CSV를 기존 대본에 추가하고 M4A를 넣은 뒤 기존 길이 측정·빌드를 진행한다. 대본이 바뀌면 해당 음원을 다시 만든다.
