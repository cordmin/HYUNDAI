# Pearl 화면 적용

## 바뀐 화면

- 진주색 배경과 파란색 버튼. 상단은 지금·수업·기록 메뉴와 실제 남은 시간, 설정이다. 가짜 OS 상태바는 넣지 않는다.
- 지금: 학교 등록 여부와 관계없이 큰 수업 카드·듣기·출발하면 듣기를 보여 준다. 하교 대화와 가 볼 만한 곳은 유지한다.
- 수업: 기존 5편과 실제 길이에 맞춘 목록·예약·멈춘 곳부터 듣기를 유지한다.
- 기록: 기기에 저장된 수업 기록·깃털·숙제와 배지 그림 6장을 보여 준다. 배지는 둘러보기이며 획득 조건·실제 지급 기능은 추가하지 않았다.

## 제거한 기능

등교 대화와 준비물 안내를 홈·주행 제안·예약·문 열림 안내에서 제거했다. 등교 시작·예약을 직접 호출해도 실행되지 않는다. 주행 중 등교 대신 시간에 맞는 수업을 제안한다.

Gleo의 준비물 기능은 schema.json, Manifest 수신 경로, Kotlin 응답 코드, WebView 저장 함수에서 제거했다. 앱을 열면 예전 준비물 응답 캐시도 지운다. Gleo에는 수업 시작·멈춤/이어 듣기 두 기능만 남는다. 하교 대화·학교 설정·내비·관광 정보는 유지한다.

## 기능과 기록 보존

기존 수업 조립·실제 음원·멈춤/이어 듣기·이전·구간/초 단위 탐색·도착에 맞춘 분량 변경·중단 위치·깃털·숙제를 사용한다. 새 메뉴에서 기록·설정으로 나가면 재생을 닫아 소리와 수업 상태가 따로 남지 않게 한다. 주행 중에는 구간 이동과 기록·설정 탐색을 허용하지 않는다.

앱 버전은 0.4-pearl이다. `dait-preview.html?app=1`은 브라우저에서도 앱 창 전체 크기로 확인하는 프리뷰 주소다. 프리뷰 시연 버튼은 기존처럼 제출용 앱과 실제 주행 중 숨긴다.

## 확인 범위

- JavaScript·중계 서버 207개 시험 통과. 새 메뉴·기록·제거한 호출과 기존 수업 기능을 함께 검사했다.
- 수업 음원 192개 누락 없음. 대본·음원 자체는 변경하지 않았다.
- 브라우저의 실제 음원 재생, 일시정지, 구간 이동, 이어 듣기, 주행 화면, 기록·배지 화면 확인.
- 665×420 기준 화면 넘침 없음과 주요 버튼 44px 이상 확인. 420×640에서도 넘침을 확인하고 작은 메뉴 버튼 높이를 보완했다.
- Android 개발 빌드·단위시험 5개·lint 통과. 최종 APK 안의 HTML·CSS·Gleo 설명서와 배지 6개 포함 여부를 대조했다. 이번 작업에서 Android 기기에 직접 설치해 실행하지는 않았다.

최종 기획서·시연 영상은 기존 담당자가 바뀐 화면과 삭제한 기능에 맞춰 대조해야 한다. 이번 화면 적용을 다른 담당자의 검토·영상·제출 완료로 기록하지 않는다.
