# 교사 규칙표 사용법

`교사규칙표.csv`가 다잇의 핵심 자산입니다. 시험, 체험학습, 축제 같은 날에 앱이 무슨 말을 할지 이 표가 정합니다. 코드를 몰라도 고칠 수 있습니다.

지금 표는 **초안**입니다. 선생님들이 대사를 읽어 보고 고쳐 주세요.

## 고치는 방법

1. `교사규칙표.csv`를 엑셀로 엽니다.
2. 고치고 싶은 칸을 고칩니다. 새 규칙은 맨 아래 줄에 더합니다.
3. 저장할 때 파일 형식을 **CSV UTF-8(쉼표로 분리)** 로 고릅니다. 그냥 CSV로 저장하면 한글이 깨집니다.
4. 앱을 빌드하면 표가 자동으로 반영됩니다.

표에 잘못된 칸이 있으면 빌드할 때 몇 번째 줄이 문제인지 알려 줍니다.

## 칸 설명

| 칸 | 뜻 | 쓸 수 있는 값 |
|---|---|---|
| 번호 | 규칙 번호. 음원 이름에 쓰이므로 겹치면 안 되고, 한 번 정하면 바꾸지 않습니다 | 숫자 |
| 순위 | 같은 날 규칙이 여럿 맞으면 숫자가 작은 것을 씁니다 | 숫자 |
| 이름 | 사람이 알아보기 위한 이름 | 자유 |
| 여정 | 언제 쓰는 규칙인가 | 등교, 하교, 모두 |
| 학교급 | 어느 학교에 쓰는가 | 전체, 초, 중, 고, 중고 |
| 일정 낱말 | 학사일정 이름에 이 낱말이 있으면 맞습니다. 여러 개는 `\|`로 나눕니다 | 예: `시험\|고사\|지필` |
| 시점 | 그 일정의 어느 때인가 | 당일, 마지막날, 전날, 앞둔 기간(2~7일 전) |
| 과목 | 오늘의 질문 규칙에서 시간표 과목 | 예: 과학 |
| 화면 제목 | 첫 화면과 대화 화면의 큰 글씨 | 짧게 |
| 화면 설명 | 첫 화면의 작은 글씨 | 짧게 |
| 준비물 칸 | 첫 화면 준비물 칸. 없으면 `없음` | 짧게 |
| 대화 방식 | 대화를 어떻게 이어 가는가 | 아래 표 참고 |
| 첫 말 | 앱이 먼저 하는 말 | 한두 문장 |
| 끝 말 | 답을 들은 뒤 하는 말 | 한 문장 |
| 주의할 점 | 대사를 쓸 때 지킬 기준. 앱은 읽지 않습니다 | 자유 |

| 대화 방식 | 흐름 |
|---|---|
| 확인 | 첫 말 → 「다 챙겼어」·「깜빡했어」 → 끝 말 |
| 이야기 | 첫 말 → 아이가 자유롭게 말함 → 끝 말 |
| 안내 | 첫 말과 끝 말을 이어서 말하고 끝남 |
| 질문 | 소리 없이 첫 화면의 「오늘의 질문」에만 나옴. 화면 제목에 질문을 씁니다 |

남은 시간이 짧으면 앱이 스스로 줄입니다. 2~5분 남았으면 첫 말만 하고, 2분 이하면 규칙 대신 「가방과 준비물을 챙겨요」로 마칩니다.

## 대사를 쓸 때 지킬 기준

- 학교 안내가 앱보다 우선입니다. 준비물과 복장은 단정하지 않습니다.
- 점수, 등수, 잘했는지를 묻지 않습니다.
- 아이가 말하지 않아도 되게 씁니다.
- 앱이 모르는 사실(시험 범위, 행사 장소, 금식 여부)을 지어내지 않습니다.
- 한 번에 두 문장을 넘기지 않습니다. 운전 중에 듣는 말입니다.

## 음성은 어떻게 만들어지나

대사를 고치거나 규칙을 더하면 빌드할 때 `voice/규칙-대본.csv`가 다시 만들어집니다. 이 표의 `상태`가 `완성`이 아닌 줄이 음성 제작에 넘길 대본입니다. 시간표와 남은 시간을 이어 말할 조각 대사(`rules/음원조각.csv`)도 함께 들어 있습니다.

받은 음원은 표의 `음원 이름` 그대로(예: `r1_1.wav`) `android/app/src/main/assets/voices/nika/`에 넣습니다. 그러면 임시 음성 대신 그 음원을 씁니다.

대사를 고쳤는데 같은 번호의 음원이 이미 있으면 옛 말을 그대로 틀게 됩니다. 이때는 그 음원 파일을 지우고 새로 받아 주세요.

`tools\Make-Temp-Voice.ps1`은 음원이 오기 전에 흐름을 시험할 임시 음성을 Windows 한국어 음성으로 만듭니다. 제출용 음성이 아닙니다.
