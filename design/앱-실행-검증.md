# 레이아웃 기준 첫 Android 앱 검증

2026-10-30. 최종 시각 디자인을 확정한 것이 아니라, 선택한 좌측 동행 요소·우측 안내·하단 조작 구조를 검증했다.

- `Build-App.ps1 -Install` 완료: assembleDebug, testDebugUnitTest, lintDebug 성공.
- 상태 단위 테스트 3개: 실패 0. 상태 불명·주행 제한, 건너뛰기, 장면 변경 시 정지 검증.
- lint 오류 0. 백업 설정 관련 경고 1개: allowBackup=false 및 fullBackupContent=false를 지정했으나 검사기는 XML 리소스를 권고한다.
- Pleos 2.1.0 / Android 14 / API 34에 설치하고 MainActivity 실행 확인.
- 주차 상태를 CarUxRestrictionsManager에서 읽어 조작 활성화 확인. DO 선언하지 않음.
- 기본 한국어 TTS 부재를 확인하고 로컬 예시 WAV 대체 재생 추가. 에뮬레이터 오디오 포커스 요청·종료 이력 확인.
- 주차 중 장면 선택창과 하교 선택 동작을 화면에서 확인.
- 앱 실행 이미지: `design/app-layout.png`. APK: `apk/DAIT-layout-debug.apk`, 개발 검증용 debug 서명.
- SHA-256: `A4CCC17DD05B48DB5F3960457403C4DC8C8B4DC1BB0DC79FC26A519BA97EAC84`.

한계: 학교/내비/ETA는 예시이며 Pleos 전용 SDK·NEIS·Gleo 연동은 아직 없다. 주행 중 기능 허용 승인을 뜻하지 않는다. 실제 주행 전환 및 내비 음성과의 경쟁 재생은 후속 통합 테스트가 필요하다.

빌드는 Windows Java AF_UNIX 연결 오류와 한글 경로의 테스트 클래스 로딩 문제를 우회했다. 과정에서 다운로드한 진단용 JDK는 실제 최종 빌드에 사용하지 않았다. 해당 임시 다운로드 정리는 자동 승인 검토에 차단되어 남겨두었다. 최종 빌드는 기존 JBR 21을 사용한다.
