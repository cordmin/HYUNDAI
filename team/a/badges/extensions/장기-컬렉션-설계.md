# 몇 년 동안 이어지는 배움 컬렉션

2026-11-10 사용자 정정 반영. 10종은 현재 앱에 있는 그림 수일 뿐이며 배움의 전체 목표가 아니다. 같은 차를 오래 타는 동안 다양한 지식·질문·시리즈를 만나도록 120종의 출발 목록을 설계했다. 이 개수에 상한을 두지 않고 새 콘텐츠와 함께 확장한다. 운전 거리·주행 시간·차량 이용 횟수는 배지 조건으로 쓰지 않는다.

## 수집 경로 네 가지

| 경로 | 출발 규모 | 무엇이 달라지는가 |
|---|---:|---|
| 주제 탐험 | 72종 | 12분야마다 첫 발견 1종 + 세부 주제 5종. 같은 그림에 숫자만 바꾸지 않고 주제 장면을 담는다. |
| 분야 연결 | 24종 | 개념 연결 20종 + 탐색 범위 4종. 시와 별, 리듬의 수학, 지도와 역사처럼 배운 것을 엮는다. 한 분야 안의 서로 다른 개념 연결도 포함한다. |
| 시리즈 완주 | 12종 | 제작자가 묶은 이야기별 다른 책·장면·문양. 현재는 편성 후보이며 공식 시리즈 자료는 빈 목록이다. |
| 누적 기록 | 12종 | 서로 다른 수업 1·3·10·30·100·300편, 수업을 마친 날 누적 5·20·50·100·300·600일. 연속 출석이 아니다. |

대부분은 새로운 주제·연결·시리즈를 발견하는 배지다. 오래 이용한 경험은 별도의 누적 기록에 남긴다. 공개 수업과 사람마다 듣는 속도가 다르므로 특정 개수로 몇 년을 보장하지 않고 콘텐츠 공급과 함께 다음 목표를 연다.

## 학생과 성인 모두의 관심사를 담는 12분야

언어·문학, 수리·논리, 자연·과학, 기술·디지털, 사회·시민, 역사, 지리·세계, 경제·금융, 건강·생활, 음악, 미술·디자인, 문화·철학.

학년은 배지 등급으로 쓰지 않는다. 누구나 쉽게 시작·원리 이해·생활에 연결하는 깊이를 선택할 수 있다는 설계다. 쉬운 판·짧은 판도 완료는 동등하게 인정하며 같은 수업의 다른 깊이·판은 하나의 canonicalLessonId로 센다. 세 깊이의 대본과 선택 기능은 아직 없다.

## 계속하고 싶게 만드는 화면 구조

- 지금 도전 중: 달성에 가까운 목표 최대 3개와 바로 들을 수 있는 수업을 함께 보여 준다. 전체 미획득 120개를 한꺼번에 펼치지 않는다.
- 나의 컬렉션: 획득한 배지를 주제·시리즈별로 모아 획득일과 수업을 다시 볼 수 있게 한다. 완주 뒤 새 편이 추가돼도 기존 획득은 유지한다.
- 새로 열린 컬렉션: 새 대본·제작자 시리즈가 준비되면 해당 배지 묶음을 공개한다. 이후에도 새 주제·연결·시리즈를 등록할 수 있다.
- 이달의 발견: 이미 공개된 수업으로 구성한 선택형 탐색 경로다. 기간이 지나도 해당 배지를 지우거나 박탈하지 않으며 초조한 카운트다운을 붙이지 않는다.

기존 6종의 은색 테두리·입체 에나멜·장면 일러스트를 유지한다. 주제 배지는 대표 사물과 장면, 연결 배지는 두 개념이 만나는 장면, 시리즈는 책과 이야기의 문양, 기록은 숫자와 누적 경험으로 구분한다. 대표 24종은 스타일 검토용 재현 이미지이며 새 개별 PNG 24개가 앱에 반영된 것은 아니다.

## 대본과 함께 운영하는 규칙

1. 콘텐츠에는 canonicalLessonId, fieldId, topicIds, 필요하면 제작자 seriesId·requiredEpisodeIds·version을 둔다. 현재 수업에 이 태그를 임의로 일괄 붙이거나 공식 시리즈를 생성하지 않는다.
2. 분야 첫 발견은 해당 분야 1편, 세부 주제는 서로 다른 3편을 제안한다. 주제 자료가 3편 미만이면 아직 목표로 공개하지 않는다.
3. 개념 연결은 양쪽 주제를 각각 2편씩 총 4편 이상 듣는 안이다. 한 수업을 양쪽 조건에 중복 계산하지 않는다. 서로 다른 배지 간에는 같은 완료 수업을 재사용할 수 있다.
4. 완주 대상 필수편은 공개 시점의 버전으로 보존한다. 필수편 음원이 모두 준비된 시리즈만 공개하며 새 편·새 시즌은 별도 목표로 추가한다.
5. 배지 획득·서로 다른 수업 ID·누적 학습일은 최근 수업 기록 보관 개수와 별도의 영구 원장으로 보존한다. 새 배지를 추가해도 이미 획득한 것을 다시 잠그지 않는다.
6. 완료는 듣는 경험의 기록이며 이해도·전문성·학년 수준을 인증하지 않는다. 주행 중 획득 팝업·효과음·추가 조작·방문 장소·차량 거리 조건은 넣지 않는다.

- [대표 24종 시안](장기배지-대표24종.png): 원본 6종과 같은 레퍼런스의 확장 디자인을 한 장에 제시.
- [120종 읽기용 목록](배지-120종-설계목록.md), [CSV](catalog-v2.csv), [JSON](catalog-v2.json): 안정적인 ID, 분야, 제안 조건, 공개 전제. 전부 proposal 상태로 실제 획득에 연결하지 않았다.
- 현재 앱: 기존 6종 + 승인받은 4종의 둘러보기. 자동 획득 없음.
- 다음 구현: 콘텐츠 태그·획득 원장·조건 계산·현재 가능한 목표 선정·주차 후 컬렉션 확인. 이후 실제 개별 배지 그림을 순차 납품한다.

이 설계는 사용자 요청에 따른 장기 확장 제안이며 팀의 획득 조건 확정, 새 대본 제작, 120개 개별 아트 납품이나 자동 지급 구현을 완료한 것으로 기록하지 않는다.
