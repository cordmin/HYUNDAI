# 음악 수업 앱 통합

2026-11-06 사용자 요청에 따라 기존 수업 목록·시간 맞춤 조립기·음원 재생기에 통합했다. 앱용 원본은 `lessons/박과리듬.csv`이고, 수업 ID는 `rhythm`, 과목은 `음악`이다. `dait-preview.html`에서 수업 고르기 → 음악을 선택해 듣는다. 열려 있던 프리뷰는 새로고침한다.

- 앱용 M4A 36개: 짧은 판 11·원래 판 11·확장 묶음 12·복습/도착 정리 2개. `android/app/src/main/assets/voices/lesson/rhythm_*.m4a`.
- 예시는 음원에 포함한다. 기본 발문은 앱이 답할 틈을 주고 선택 시 답을 기록한다. 선택 확장의 질문·생각할 틈·해설은 하나의 음원으로 묶어 시간 조정 때 질문만 남지 않게 했다. 기본 발문의 기다림을 음원과 앱에 중복으로 넣지 않는다.
- 실제 앱 조립 길이(복습·뒤 수업 제외): 8분 선택 440.64초(7:20.64), 15분 881.36초(14:41.36), 20분 1172.36초(19:32.36), 30분 1355.60초(22:35.60). 앱은 개별 조각을 조립하므로 기존 완성판 M4A 세 벌과 구성·길이가 다를 수 있다.
- 기존 일시정지·이어 듣기·이전·도착 시간 조정·중단 지점·완료 기록·숙제·보상 처리를 그대로 사용한다. Gleo 과목 목록에도 음악을 넣었다.

재생성은 `python team/a/voice/integrate_music.py`. 이미 생성한 원본 WAV와 지문을 확인해 앱용 음원을 내보내며 TTS API는 호출하지 않는다. `tools/build-lessons.js`와 일반 앱 빌드를 다시 실행해도 음악 등록을 유지한다.

검사: 시간별 조립·음원 경로·Gleo 과목·중단 후 이어 듣기·도착 정리, 프리뷰 코드에서 실제 음악 선택·음원 재생 요청·일시정지/재개·이전·완료 기록을 확인했다. 기존 시나리오는 수업 목록 변화와 분리하고 음악 통합 시나리오를 별도로 추가했다. 실제 브라우저 조작 확인은 컴퓨터 도구가 현재 URL을 판별하지 못해 중단됐다. 사람의 내용 검수·음원 전수 청취 승인은 하지 않았다.
