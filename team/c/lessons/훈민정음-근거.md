# 훈민정음 근거

갈래 C 초안. 교사 검수 전. 확인 날짜는 모두 2026-11-02.

## 교사가 판단할 것

1. **"어리석은 백성"(b1, b10).** 원문의 「愚民」, 「愚者」를 그대로 옮긴 말이다. 그대로 둘지 "글을 모르는 백성"으로 풀지 정해야 한다.
2. **"윗잇몸"(b4).** 원문 「舌附上腭」의 上腭을 흔히 쓰는 말로 옮겼다. 낱말 뜻 그대로는 위턱이나 입천장에 가깝다. 어느 말을 쓸지 판단이 필요하다.
3. **q2의 비교.** 뜻을 담은 글자와 소리를 담은 글자를 견주는 평가 발문이다. 한자를 낮추어 보는 뜻으로 들리지 않는지 판단이 필요하다.
4. **b11의 전서 논쟁.** 해석이 갈리는 대목이라 "견해가 많고, 다르게 보는 학자도 있습니다"로 썼다. 빼도 수업이 성립한다.
5. **c1의 "소리를 설명하는 그림".** 내 표현이다.

## 확인 안 함

- **판본:** 위키문헌의 해례본 입력본을 읽었고, 해례본 영인본과 글자 하나하나 대조하지 않았다.
- **한문 풀이:** 제자해와 정인지 서문의 한문을 내가 직접 읽고 풀었다. 학계의 공식 번역과 대조하지 않았다. 교사 확인이 필요하다.
- **자모 이름:** 옛이응, 여린히읗, 반시옷, 아래아는 흔히 쓰는 이름이다. 표준 근거 페이지를 열어 확인하지 않았다.
- **네 글자가 쓰이지 않게 된 시기와 사정:** 확인하지 않아 대본에 넣지 않았다. 「한글」 항목에서 스물네 자와 몇 글자의 소멸은 확인했으나, 네 글자를 한 번에 적은 대목은 보지 못했다. b12의 네 글자는 해례본 스물여덟 글자와 오늘날 스물네 글자를 견주어 뽑았다.
- **"오백 년도 더 된":** 1443년과 오늘을 견준 내 계산이다.

## 일부러 넣지 않은 것

- 최만리의 반대 상소. 연 자료에서 연도를 확인하지 못했고 오늘의 질문과도 멀다.
- 한글날의 날짜 유래, 2008년 상주본, 한글이 세계에서 가장 과학적이라는 식의 평가.
- 음양오행과 계절을 짝지은 설명. 해례본에 있으나 차에서 듣기에 어렵다.
