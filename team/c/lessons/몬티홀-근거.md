# 몬티홀 근거

상태: 교사 검수 전 초안. 작성: 갈래 C. 확인 날짜는 모두 2026-11-02이다.

## 교사가 판단할 것

1. b1은 사회자 규칙을 세 가지로 말한다. 참가자가 자동차를 골랐을 때 두 염소 문 가운데 어느 쪽을 같은 확률로 여는지는 말하지 않았다. 이 조건은 어느 문이 열렸는지까지 따질 때 필요하고, 수업의 삼분의 이 결론은 이 조건 없이도 전체 경우로 성립한다. 넣을지 정해 주세요.
2. b3의 경우 나누기는 중학교 확률의 "경우의 수가 같은 가능성"에 기대고 있다. 조건부확률이라는 말은 쓰지 않았다. 이 정도가 알맞은지.
3. b8의 여섯 가지 경우 설명이 소리만으로 따라갈 만한지. 필수가 아니다.
4. b10의 심술궂은 사회자는 설명을 위해 만든 규칙이다. 실제 방송의 규칙이 아니다. 수업에 둘지.
5. q3는 일상의 "반반"을 묻는다. 개인 사정을 말하게 하지는 않지만 어조가 괜찮은지.
6. 대사의 자동차와 염소 그림은 원래 문제의 관습을 그대로 따랐다. 차 안에서 듣기에 알맞은지.
